# 03 — User Journeys (as publicly described)

## J1 First run
Buy → email with installer + key → run installer → app auto-starts, docks bottom → taskbar goes auto-hide → paste key → Activate (E-07 §1).

## J2 Arrange the dock
Right-click dock → Widgets… → browse category / search → click tile (added at end) → drag to reorder → click "−" to remove → close picker (E-07 §2).

## J3 Move dock to top
Drag empty spot → release in top half → snaps top; cards now open downward; position remembered (E-07 §3).

## J4 Connect Claude session tile (developer)
Install Claude Code → `claude` → sign in → add Claude Usage tile → click tile → card → "Check again" → tile shows session % + reset, weekly % + reset (E-08).
Failure state: "The tile stays locked" → sign in, press Check again.

## J5 Connect a revenue store
Click sample tile → card explains needed read-only key → create in provider dashboard → paste → tile shows real 30-day revenue (E-07 §6).

## J6 Calendar
Calendar card → Calendars → paste secret iCal link → events appear within 15 min, merged with renewals/payouts (E-05).

## J7 Day-to-day glance
Look at dock: next meeting countdown, AI session %, revenue, now playing; alert line appears above dock when something needs attention ("ChatGPT weekly limit runs out tomorrow at 2:00 PM") (E-01).

## J8 Fullscreen
Game/video fullscreen → dock hides → returns on exit (E-07 §5).

## J9 Update / uninstall
Update button appears on dock → one click → restart. Uninstall via Windows Settings → taskbar restored (E-07 §7–8).
