# 01 — Product Overview (reference product: lumabar)

Source: public site https://lumabar.xyz/ (home, /widgets, /docs, /docs/connect-claude), captured 2026-10-30.
Evidence IDs (E-xx) refer to `07-evidence-register.md`.

## What it is
A Windows 10/11 desktop **dock that replaces the taskbar** and hosts **live widgets** (E-01, E-02).
Tagline positioning: "Not a taskbar. A smart dock." — "100+ live widgets that work together" (E-01).

## Who it targets (E-03)
Four personas shown as preset layouts: **Founders** (revenue, visitors, followers), **Developers**
(commits, Claude/Cursor limits, Linear, Supabase, CPU), **Sellers** (Shopify, Paddle, Gumroad…),
**Students** (focus timer, todos, music, screen time).

## Core value propositions
1. Stop opening apps to check things — status lives on the dock (E-03).
2. Widgets share data and trigger "automations": pause music before meetings, warn before an AI limit
   runs out, ask before a subscription renews (E-05 FAQ).
3. Local-first privacy: no account, no vendor server, no telemetry; keys stay on the PC (E-07).
4. Visual polish: "Liquid Glass" refraction of the wallpaper, six styles, top/bottom, pill/full width (E-04).

## Business model (E-06)
One-time $5.99 (launch, list $15.99), lifetime license, free updates, 14-day refund, sold via Polar.
One key activates one PC. 64-bit and 32-bit builds.

## Distribution & lifecycle (E-07)
Installer + key by email → installer auto-starts app → docks bottom → paste key → Activate.
Auto-update check 1 min after start then every few hours; one-click update + restart.
Uninstall through Windows Settings; taskbar restored.
